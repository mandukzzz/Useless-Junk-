Backup e restauração

⬇ Exportar backup completo

Cria um arquivo JSON com suas anotações, conteúdos, etiquetas, links, tópicos do mapa mental e marcações salvas. Arquivos locais importados como imagem/PDF também entram no backup, podendo deixá-lo grande.

⬆ Restaurar backup

Escolha um arquivo de backup JSON criado por este aplicativo. A restauração substitui os dados atuais; exporte um backup antes se quiser guardá-los.

Armazenamento

Verificando armazenamento...

Privacidade: os dados são guardados localmente neste navegador/dispositivo. Limpar os dados do navegador, desinstalar o app ou usar outro navegador pode apagar ou separar os dados. Faça backups regulares e mantenha uma cópia fora do celular.

Novo conteúdo

Vídeos externos precisam de internet. Para uso offline, anexe um vídeo ou arquivo que você tenha permissão para armazenar no aparelho. Alguns PDFs podem abrir no visualizador do navegador.
